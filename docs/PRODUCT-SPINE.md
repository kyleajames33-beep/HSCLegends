# HSC Legends — Product Spine (the "what is this game" decision)

_Agreed with Kyle 2026-07-03. This is the shape everything should build toward. If a feature doesn't serve one of the layers below, it's probably noise._

## One-line pitch
**The Duolingo of the HSC** — a phone-first game where NSW HSC students answer real syllabus questions (with feedback), and every fun/social/collectible mechanic exists to make them keep doing it.

## Who / when / why
- **User:** NSW HSC student, Year 11–12 (16–18), on their phone.
- **Atomic action:** answer one HSC MCQ **and get told why**. Everything else is scaffolding. The studying must stay *real* — that's the edge over Blooket.
- **Occasions:** bus/between-class micro-sessions (2–5 min) · "I have a test Friday" cram · "am I improving?" reassurance · "my mate dared me" social · new-week/term FOMO.

## Acquisition vs retention (the key call)
- **Acquisition = the live Class Game** (teacher-launched via hscscience.com.au). A teacher runs it in class → students see it's fun → install it.
- **Retention = the solo Daily Ritual.** Once installed, the daily habit keeps them coming back alone.
- One door in (class), one habit that keeps them (daily). Don't confuse the two.

## The spine — 3 layers, one progression
Every layer feeds the **same currencies** (XP, Sparks, mastery), so anything a student does advances everything.

1. **TODAY — the ritual (hook, ~5 min/day).** The hero of the home screen: one prescribed daily set → keeps the streak → feeds league, quests, season, event. This is the retention engine. *Home shows ONE obvious "beat today", not a menu of 15.*
   - Routes: daily quizzes, `/rewards` (spin/quests), `/play`.
2. **STUDYING FOR SOMETHING? — the value (when a test looms).** The "get a Band 6" layer that makes it a study tool, not just a game.
   - Routes: `/review` (SRS), `/topics` (past-papers-by-topic), `/exam`, `/progress` (mastery + predicted band), `/type`.
3. **PLAY — the dopamine (when they want fun/social).**
   - Routes: `/knockout` `/duel` `/heist` (Arena), `/campaign`, `/match`, `/event`, `/collection`, `/friends`, `/tycoon`, `/hq`.

**Connective tissue (meta / identity):** Sparks, Legend cards, level, streak, `/league` division, `/season` term pass, `/achievements`, `/profile`. This is what makes it feel like *your* game.

**Acquisition surface (teacher/class):** `/join` `/host` `/classes` `/boss` (weekly class co-op).

## Design principles
- **Front door = one mission, not a grid of equals.** (Duolingo shows one lesson.)
- **Solo must always work** (Campaign + bots) — most players won't have a live class of 30.
- **Never sell currency/answers/advantage.** Cosmetics only, earn-only, published odds.
- **Lead with learning** — explanations, mastery, verified questions, predicted band. If it doesn't move marks, cut it.

## What NOT to build
More parallel game modes with no tie to the daily ritual; anything that makes luck/speed beat mastery; paid loot; guilt notifications.
